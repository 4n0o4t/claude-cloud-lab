# 月夜狼人杀：3D 圆桌原型

- 日期：2026-11-05
- 状态：原型完成，补丁待所有者合入（本会话对 wolfai-killer 只有只读权限）
- 分支：`claude/bold-bell-wrvw3m`
- 来源：所有者看了宣传片第二版（`experiments/2026-11-03-wolfai-promo/`）后提出，片里的 3D 圆桌可以作为产品里原来 2D 圆桌的升级。

## 问题

宣传片里的伪 3D 圆桌能不能搬进 wolfai-killer 的对局页（`redesign` 分支 `88c41e7`），替换原来的 2D 圆桌，又不破坏任何现有功能？

## 先审视原来的 2D 圆桌

**它承担的东西**（`frontend/src/views/GamePlay.vue` 的 `.arena`，坐标来自 `frontend/src/gamePlayUi.js`）：

- 座位是 `<button>`，点选行动目标，丘比特点两个。
- 状态都挂在座位的 class 上：
  - 本人 `is-me`、发言中 `is-speaking`、选中 `is-selected` / `is-paired`；
  - 等待真人 `is-waiting`（呼吸红光）、出局 `is-dead`（灰化）；
  - 阵营描边 `camp-*`，只在上帝视角或本人可见。
- 投票时有计票角标 `sn-badge`，还有 SVG 投票连线 `vote-web`。
- 桌心按阶段换内容：待开局、天黑、当前票数、最新发言。
- 窄屏（≤900px）缩小。

**问题**（见 `shots/6p-vote-2d-vs-3d.jpg` 左半）：

1. **空间浪费**：1920 宽时舞台约 1316px，圆桌却是不超过 680px 的正方形，两侧大片空着。
2. **投票连线横穿桌心**：虚线直接压在“当前票数”的字上。
3. **画面平**：所有座位一样大，看不出“围坐一桌”。

## 方案取舍

- **不用 WebGL 或 three.js。** 沿用宣传片的做法：把圆按倾角压成椭圆台面，座位按纵深缩放、排层级（近大远小），加落影。
  - 座位仍是原来的按钮，点选、键盘焦点、所有状态 class 和样式原样生效；
  - 不新增依赖，低端机也没有负担。
- **镜头不动。** 宣传片里桌子会缓慢旋转，但产品里旋转会让点选目标跟着跑，所以不转。
- **自己的座位转到正前方**，像真坐在桌边；旁观时 1 号在远端正中，和 2D 一致。
- **投票弧线朝桌外鼓出**，避开桌心文字。正对面两座的长弦封顶并压在桌心文字之下，不挡字。
- **能切回 2D**：阶段栏加“平面 / 立体”按钮，选择记在 `localStorage` 的 `wk.arena.mode`。屏宽 ≤640px 自动用 2D，手机宽度下椭圆桌的座位会挤。
- **没有搬过来的**：宣传片里的夜间行动弧线（狼刀、守卫、查验）。这些在产品里是秘密信息，只有上帝视角能看；要做的话应该作为上帝视角的单独功能另议。

## 第一版原型被评“不如宣传片精致”，按片子的质感重做

所有者看了第一版原型的截图后说“为啥感觉不如宣传片里面的精致”。把宣传片帧和产品截图并排看（`shots/trailer-vs-product.jpg`），差距在视觉层，不在几何：

| | 宣传片 | 第一版原型 | 第二版怎么改 |
|---|---|---|---|
| 台面 | 只有两圈发丝金线，浮在光里 | 深色实心盘加灰边，像一块浑浊的板 | 去掉填色和厚度，留金线，内圈再加一道更淡的线 |
| 氛围 | 夜里深蓝、白昼暖色，有光晕 | 底色一成不变 | 桌下加按阶段变的氛围光：白昼暖金、夜里冷蓝、投票泛红；夜里金线也转冷 |
| 座位 | 大号圆章，号码清楚 | 62px 小圆、9px 标签 | 圆章直径按桌宽 × 人数（`cqw`，6 人约 85px，16 人约 50px），号码随直径缩放，标签放大 |
| 状态 | 目标座位的描边发红、发金光 | 几乎不发光 | 发言、等待、选中、票数领先时描边发光，脚下台面亮起光斑；发言者轻微抬起 |
| 投票线 | 发光实线，优雅上拱 | 灰蓝细虚线，外鼓得别扭 | 发光实线弧，从圆章边缘向上拱起；领先者的弧线染红，目标端带圆点 |
| 动效 | 弧线描出，元素弹出 | 全静止 | 座位依次落座、弧线从投票者描向目标；`prefers-reduced-motion` 时关闭 |

宣传片里桌子会转、镜头会推，这两样仍然不搬：产品里转动会让点选目标跑掉。

## 改动（`patch/0001-arena-3d.patch`）

改了 2 个文件，新增 319 行、删除 18 行：

- `frontend/src/gamePlayUi.js`：新增 `arena3dGeometry`、`arena3dDiscPct`、`getSeatPose3d`、`getPlayerPositionStyle3d`、`getVoteArc3d`。原来的 `getPlayerPositionStyle` 和 `getVoteLineCoords` 不变。
  - 人多时桌面立起来一点：倾角 0.42，9 人以上 0.46，13 人以上 0.5，两侧座位纵向不挤。
- `frontend/src/views/GamePlay.vue`：
  - 加入切换开关和窄屏判断；
  - 3D 用 16:9 台面，用 CSS 变量传入椭圆半径；
  - 投票改为 `path` 弧线，新增 `voteLeadSeats`，以及座位的 `has-votes` 和 `is-vote-lead` 状态；
  - 新增 3D 样式：上表所列，另有 13 人以上隐藏重复的“座 xx”标签。

所有者合入方法（在 wolfai-killer 仓库里）：

```bash
git checkout redesign && git am /path/to/0001-arena-3d.patch
```

## 验证

在容器里跑真实前后端，台词由宣传片实验的 `tools/mock_llm.py` 驱动。截图脚本在 `tools/`。

- `tools/shoot.mjs`：拍 6 人局白天发言中、6 人局投票中、12 人和 16 人待开局四种状态，每种分别用 1920、1366、390 三种宽度。2D 原版、3D 原型、原型切回 2D 各拍一套。
  - 3D 下 6、12、16 人都不重叠。重做时第一轮圆章固定 84px，16 人局在 1366 宽下挤成一团，改为按桌宽 × 人数缩放后复拍通过；同一轮还修了右侧两座纵向对投时弧线甩出桌外的问题。
  - 切回 2D 与原版一致；
  - 390 宽自动回退 2D，切换按钮隐藏。
- `tools/shoot-player.mjs`：真人坐 3 号开局。
  - 夜里最靠前的座位是“你 · 03”；
  - 点“平面”后 `.arena` 不再有 `is-3d`，`localStorage` 记为 `2d`。
- 几何函数在浏览器里经 Vite 加载核对：
  - 本人座位纵深为 1（最前）；
  - 旁观时 1 号纵深为 0（最远）；
  - 原 2D 函数输出不变。
- `vite build` 通过；补丁对干净的 `origin/redesign` 执行 `git apply --check` 通过；补丁不含 `config.yaml` 或密钥。

**未验证**：

- 上帝视角下的阵营描边和立绘：旁观页的上帝按钮有已知问题，见宣传片实验 README。
- 丘比特连两人、猎人开枪等真人操作的点选，在 3D 下没有逐一点过。点选逻辑没改，只改了坐标。
- 1280 到 900 宽之间的平板竖屏。
- 没有自动化测试：仓库前端目前只有 Playwright e2e 配置，`tests/` 不在仓库里。

## 结论

- 可以作为升级，而且改动很小：这是纯视图层的改动，交互和状态逻辑不动，2D 随时可切回。
- 建议所有者合入后在真实对局里用一两局，重点看真人点选和上帝视角。确认没问题后，再决定 2D 是长期保留为备选，还是只留作窄屏回退。
- 后续可选：
  - 上帝视角的夜间行动弧线（宣传片里那套）；
  - 发言时座位轻微抬起；
  - 出局时圆盘碎裂动画。
